Arquitectura (hexagonal) y resolución multi-tenant

URL pública (prod)          API
──────────────────          ───────────────────────────────
/demo ─→ tenant(slug)       GET /api/demo/services
         │                   → WHERE tenantId = tenant.id
         ├─ queries filtran   → paginación por cursor
         │  tenantId SIEMPRE  → metadata JSONB incluida
         └─ sesión admin: JWT con tenantId + rol

Slices Zustand

  • cart — carrito por tenant (persistido)
  • auth — sesión + rol
  • theme — tema en vivo
  • ui — vista/idioma/modales

Rutas

  • Públicas: /api/[slug]/{content,services,professionals,locations,availability,appointments,orders}
  • Privadas: /api/admin/* (auth + tenantId)
  • Super: /api/super-admin/tenants
